# Anindita Das Mimi — Portfolio

A responsive, motion-rich professional portfolio website for GitHub Pages. The site uses only HTML, CSS and vanilla JavaScript; no build step is required.

## Publish with GitHub Pages

1. Create a GitHub repository (for example, `anindita-mimi-portfolio`).
2. Extract this ZIP and upload **the contents** of the folder to the repository root. `index.html` must sit at the root, beside `assets/`.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After GitHub finishes publishing, open the URL shown in the Pages settings.

## Files

- `index.html` — complete website and responsive styling/animations.
- `assets/anindita-mimi-portrait.png` — professionally retouched portfolio portrait.
- `assets/Anindita-Das-Mimi-CV.pdf` — CV download.
- `assets/Anindita-Das-Mimi-Portfolio.pdf` — original portfolio PDF.

## Editing

Open `index.html` in a text editor to update text, links, sections, colors and animations. Replace the portrait in `assets/` using the same filename if needed. Reduced-motion preferences are supported. The typefaces load from Google Fonts; if unavailable, local system fallbacks are used.

## Notes

The content was prepared from the supplied CV and portfolio. LinkedIn is not linked because the supplied materials did not include a profile URL. Add the verified URL to the contact area in `index.html` when available.
